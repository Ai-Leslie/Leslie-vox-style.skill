# 风格块与结尾块

将以下“风格块”原样置入每一条图像提示词：

> 手工裁切的纪录片纸艺拼贴，铺陈在做旧新闻纸与档案地图表面；黑白半调照片剪贴物，带有粗粝的剪刀裁切边缘与错位的强调色描边；撕裂纸边、美纹胶带碎片、打字机说明条、橡皮图章印记；当故事需要表达关联时，加入红色线绳和黄铜图钉；采用做旧、低饱和的棕褐色、墨黑色和半调灰色调色板，只使用一个醒目的热红色信号强调色，并辅以克制的芥末黄色；仅在指定标签处使用紧缩粗体标题字；清晰可见的印刷颗粒与纸张纤维；哑光质感；平坦、均匀的纪录片式照明，搭配柔和的剪贴投影。

将以下“结尾块”原样置于每一条图像提示词的末尾：

> 每个元素都必须呈现为由真实纸张手工裁切并分层叠放的实体，具有清晰可见的剪贴边缘、半调印刷纹理，以及各层之间柔和的阴影分离。构图保持干净、极简且具有编辑设计感，并保留充足的负空间。不得是数字插画，不得是卡通，不得是 3D 渲染，不得有光泽，不得使用渐变，不得杂乱，不得有水印，不得有标志，除指定标签外不得有其他文字。高级纪录片拼贴美学，16:9，超精细，8K。
